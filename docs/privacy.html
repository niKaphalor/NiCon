Privacy policy

Last updated: September 23, 2026. This policy applies to the instance of NiCon served at this URL — the web frontend, its Cloud API (which handles your account and server list), and the local relay you run to actually connect to a server's console. See the imprint for this instance's operator contact details.

1. Who's responsible

The operator named in the imprint is responsible for data processing on this instance under the GDPR. NiCon is open-source software; anyone running their own Cloud API, relay, and copy of the frontend is responsible for the data they process — not the authors of the NiCon project.

2. What data we process

When you create and use an account, we process:

  • Username — freely chosen, no email address required.
  • Password — never stored in plaintext, only as a bcrypt hash.
  • Recovery code — a 20-character one-time code generated when your account is created (or last reset), shown to you exactly once. Like the password, only its bcrypt hash is stored — it's the only way to reset your password since no email address is on file.
  • Server data you add yourself — a game server's name, host, port, and game, plus its RCON password. The RCON password is stored encrypted (AES-256-GCM), with a key managed separately from the database.
  • Session token — a random token that identifies you after login, for up to 7 days. It's stored server-side in the database and, in your browser, in sessionStorage (not localStorage) — removed automatically when the browser tab closes.

We set no cookies and use no tracking, analytics, or third-party advertising tools.

3. Nitrado API token

When you import servers through the "Sync from Nitrado" dialog, your Nitrado API token is sent to the Cloud API once. It uses the token only in that moment, to look up your servers at Nitrado, and doesn't store it afterward — not in the database, not anywhere else. You'll need to enter it again for each future sync.

4. Purpose and legal basis

We process the data above to provide your account and RCON control over your game servers. The legal basis is Art. 6(1)(b) GDPR (performance of the usage relationship your registration establishes, or steps taken at your request, e.g. during a Nitrado sync). The session token, as a strictly necessary technical function, is additionally covered by Art. 6(1)(f) GDPR (legitimate interest in a working, secure login).

5. How long we keep it

Account and server data stays stored until you delete your account yourself (see section 7). Session tokens expire automatically after 7 days and are invalidated immediately on sign-out.

6. Sharing with third parties

Your account data and stored servers are not shared with third parties. A connection to your game server (RCON) goes directly from the relay you control or trust; a Nitrado sync goes directly from the Cloud API to Nitrado's own API — no other intermediaries are involved in either case.

7. Your rights

Under the GDPR, you have in particular the right to:

  • Access the data stored about you (Art. 15 GDPR)
  • Have inaccurate data corrected (Art. 16 GDPR)
  • Have your data deleted (Art. 17 GDPR) — you can delete your account, along with every server stored under it, yourself at any time via Settings → Delete account in the app. This immediately and irreversibly removes all your data from the database.
  • Restrict processing (Art. 18 GDPR)
  • Data portability (Art. 20 GDPR)
  • Object to processing (Art. 21 GDPR)
  • Lodge a complaint with a data protection supervisory authority (Art. 77 GDPR)

For requests beyond what the app's self-service feature covers, contact the address listed in the imprint.

8. Technical notes

The relay itself does not keep access logs with IP addresses. The Cloud API doesn't either at the application level, but it typically runs on ordinary web hosting whose server software (e.g. Apache) commonly keeps its own short-lived access logs with IP addresses by default — this is standard web server behavior outside NiCon's code, governed by the hosting provider's own logging policy. Depending on the operator's network environment (e.g. router, internet provider), technical connection data may also be logged at that layer.
